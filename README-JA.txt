Sunbreak: Downhill Club

ゲーム本体・ソースコード・テスト・設計書を同梱しています。

【PCで起動】
1. ZIPを展開します。
2. Pythonがある場合、展開したフォルダ内で次を実行します。
   python -m http.server 8000 --directory dist
3. ブラウザで http://localhost:8000 を開きます。
※ HTMLの直接ダブルクリックではJavaScriptモジュールを読み込めない場合があります。

【Web公開】
dist内の全ファイルを同じ階層のまま静的ホスティングにアップロードします。
iPhoneでは公開URLをSafariで開いてください。

【操作】
自動ペダル・着地アシストは標準で有効です。
左右/A D: ステア、Space: ジャンプ、F: 技、Q/E・1〜8: 技選択
Shift: ブースト（GOの瞬間に押すとロケットスタート）、S/下: ブレーキ
Escape/P: 一時停止、R: リスタート、M: ミュート、Enter: 開始
手動空中姿勢: I/K（着地アシストOFF時）
スマホ: 左下のボールを左右にスライドでステア（アナログ）、下に引くとブレーキ。右下は JUMP / TRICK / ⚡ / PEDAL（Androidは振動あり）
ゲームパッド: スティック ステア / A ジャンプ / X 技 / RT ブースト / LT ブレーキ / LB RB 技選択 / Start 一時停止

【v3の主な改善】
JOURNEY_MAP.md を参照してください。ステア反転の修正、サウンド（効果音・環境音・BGM）、

npm test
